Nexora AI

A modern business dashboard built with HTML, CSS, and JavaScript.
Nexora AI is a web-based product management dashboard designed to help users organize product records, track recorded sales, and monitor business performance through a clean and responsive interface.

Features

Interactive business dashboard

Product management (Add, Edit, and Delete)

Product search and status filtering

Sales information and status tracking

Dashboard statistics

Responsive user interface

Local data storage using browser LocalStorage

Technologies Used

HTML5

CSS3

JavaScript

Browser LocalStorage

Getting Started

Clone or download this repository.

Open the project folder.

Open index.html in your web browser.

No additional installation is required.

Data Storage

Product records are stored locally in the browser using LocalStorage. Data is not currently synchronized with a cloud database or server.
